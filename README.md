# Devalla Sanatana Vidya

**Ancient Wisdom for the Modern Seeker**

A living repository of Hindu spiritual knowledge, meditation, philosophy, yoga, and self-discovery rooted in Sanatana Dharma.

## Tech Stack

- **Framework**: Next.js 14 (React)
- **Styling**: Tailwind CSS
- **Fonts**: Cormorant Garamond, Source Serif 4, Noto Sans Devanagari
- **Hosting**: Vercel (free tier)

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) version 18 or higher
- [Git](https://git-scm.com/)

### Install & Run Locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
```
